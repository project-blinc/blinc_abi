# Original font fixtures

These geometric ASCII font bytes were generated by
`blinc_ts/tests/fixtures/fonts/generate.py` and are covered by Apache-2.0.
They contain no third-party font data. The TTF and WOFF2 files encode the same
original regular face, with predictable glyph advances for owned-font tests.

The generator uses Python FontTools and Brotli; tests use checked-in bytes and
do not require those tools or an installed system font.
